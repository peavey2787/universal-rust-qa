# Rule Registry v1 — Phase 1 subset

Phase 1 registers the structural rules required to populate the initial dashboard. Rule IDs are compatibility surface.

- `QA-SPRAWL-001` file line limit
- `QA-SPRAWL-002` function body length
- `QA-METRIC-001` cyclomatic complexity
- `QA-DUP-002` structural duplicate block
- `QA-DEAD-001` likely unreachable private function
- `QA-TEST-001` test inventory
- `QA-COV-001` coverage evidence unavailable marker
